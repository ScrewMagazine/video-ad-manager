Video Ad Manager for WordPress

Create, serve, and track your own VAST video advertisements directly from WordPress.

Video Ad Manager is a free, GPL-licensed WordPress plugin that lets publishers create clickable, skippable VAST 3.0 video advertisements without requiring an external advertising service.

Features:
Free Version
Create and manage one active video advertisement
Upload MP4 videos or use externally hosted video URLs
Configure click-through destinations
Set advertisement skip delays
Generate VAST 3.0 XML advertising tags
Track impressions, playback events, skips, and clicks
View basic advertising statistics
No account or subscription required
MEDIARAZZI Integration
Connect an optional MEDIARAZZI account to unlock additional capabilities:
Multiple hosted video advertisements
Weighted ad rotations
Sequential ad pods
Advanced VAST Tag Builder
Comprehensive advertising statistics
Video storage and bandwidth reporting
Hosted video delivery

MEDIARAZZI is a separate service starting at $49.95/month. The free WordPress plugin operates independently.

Installation
Install the Video Ad Manager plugin in WordPress.
Activate the plugin.
Open Video Ad Manager in the WordPress dashboard.
Create your first advertisement.
Copy the generated VAST URL into a compatible video player.

Requirements
WordPress installation with a supported PHP version
A VAST-compatible video player for ad playback
Accessible MP4 video files

Privacy
The standalone free version runs on your own WordPress installation.
Connecting MEDIARAZZI enables communication with an external advertising service. See the MEDIARAZZI Privacy Policy and Terms of Service.
